- `export_month` leaks the SQLite connection when no rows are found, because the early `return 0` skips `conn.close()`; use `with contextlib.closing(sqlite3.connect(db_path)) as conn:` or `try/finally`.
- `export_month` also leaks the connection if `conn.execute`, `fetchall`, or `write_rows` raises, because `conn.close()` is not in a `finally` block.
- `cur.fetchall()` loads the entire month of payments into memory before writing; pass the cursor straight to `write_rows` so rows stream (count them as they are written) and memory use stays bounded on large months.
