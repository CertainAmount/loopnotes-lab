- `export_month` leaks the SQLite connection when the query returns no rows, because the `if not rows: return 0` early return skips `conn.close()`.
- `export_month` also leaks the connection if `conn.execute`, `fetchall`, or `write_rows` raises, since `conn.close()` is not in a `try/finally` or `contextlib.closing(...)` block. Note that `with sqlite3.connect(...)` alone does not close the connection; it only manages the transaction.
- `cur.fetchall()` loads every payment row for the month into memory before writing. For large months, pass the cursor straight to `write_rows` so rows stream to the CSV, and use `len` tracking or a counter for the return value.
