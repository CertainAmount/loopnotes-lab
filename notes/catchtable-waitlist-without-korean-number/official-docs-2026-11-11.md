# 공식 문서 열람 기록 (조회 2026-11-11, curl로 본문 수집, 핵심 문장 요약·짧은 인용)

## ① CatchTable 도움센터 「자동 미루기 사용 가이드」 (게시 2025-04-29)
URL: https://docs.channel.io/catchtable/ko/articles/%EC%9E%90%EB%8F%99-%EB%AF%B8%EB%A3%A8%EA%B8%B0-%EC%82%AC%EC%9A%A9-%EA%B0%80%EC%9D%B4%EB%93%9C-d54e8972
- 흐름: 웨이팅 고객이 "도착인증 순번"에 도달하면 알림톡으로 도착인증 요청 → 고객이 매장 앞에서 GPS 위치정보로 인증 → 인증 고객은 입장 순서 대기, 호출되면 입장.
- 미인증: "확정순번"에 도달할 때까지 인증하지 않으면 자동으로 순번이 뒤로 밀림. 인증한 다음 순번 고객이 앞으로 조정. 밀린 뒤에도 도착해 인증하면 더 밀리지 않고 순번 유지.
- 취소: "20분 내로 도착인증을 하지 않으면 웨이팅이 자동으로 취소돼요."
- 순번 설정: 매장별 도착인증 순번·확정순번은 웨이팅 데이터 분석으로 **자동 설정**(수동 설정 없음).
- 반경: "고객의 위치가 매장으로부터 **300m 반경**에 위치했다면 도착인증이 완료됩니다."
- 대안: GPS 실패 시 매장 앞에 게시된 **도착코드** 입력. 둘 다 안 되면 매장에 문의 → 매장이 대시보드에서 직접 도착인증 처리(위치 무관).
- 자동 미루기는 원격 웨이팅 사용 필수, 매장이 상담원에게 신청해 켬. 중간/최종 확인 알림톡 기능은 자동 미루기로 대체.

## ② CatchTable 도움센터 「글로벌 버전 (영어 버전) 안내」 (게시 2025-02-17)
URL: https://docs.channel.io/catchtable/ko/articles/%EA%B8%80%EB%A1%9C%EB%B2%8C-%EB%B2%84%EC%A0%84-%EC%98%81%EC%96%B4-%EB%B2%84%EC%A0%84-%EC%95%88%EB%82%B4-e4b96776
- 010 번호가 없어 가입이 불가한 해외 고객용, 이메일 주소로 가입.
- 매장이 무료로 신청해야 영어 버전에 노출.
- 영어 버전은 예약금 환불 불가(선결제, 현장 차액 결제). 알림은 전화번호 대신 이메일(한국 번호가 있으면 기재 가능).
- 빈자리 알림, 동행인 초대 등 일부 기능 없음. 해외 카드로만 결제.

## ③ CatchTable 도움센터 「웨이팅 다국어버전 오픈」 (게시 2025-07-21) — 선택 검색에서 찾음
URL: https://docs.channel.io/catchtable/ko/articles/%EC%9B%A8%EC%9D%B4%ED%8C%85-%EB%8B%A4%EA%B5%AD%EC%96%B4%EB%B2%84%EC%A0%84-%EC%98%A4%ED%94%88-7ecfe279
- 매장이 요청하면 약 1주일, 추가 비용 없음. "외국인 손님들은 번호가 없기 때문에 이메일로 확인 가능합니다."
- 다국어 웨이팅에서 도착인증이 어떤 채널로 오는지는 문서에 없음(못 찾음). → 본문은 "이메일·앱 알림 켜 두기"까지만.

## ④ CatchTable 도움센터 「웨이팅 설정 > 알림 설정」 (게시 2025-03-12)
URL: https://docs.channel.io/catchtable/ko/articles/%EC%9B%A8%EC%9D%B4%ED%8C%85-%EC%84%A4%EC%A0%95--%EC%95%8C%EB%A6%BC-%EC%84%A4%EC%A0%95-ba20be28
- 중간/최종 확인 알림톡 발송 순서를 **매장이 입력**(예: 5번째), 고객 응답 시간과 자동취소 여부도 매장 설정.
- 코드입력형: 매장이 도착코드와 코드 위치를 등록, 손글씨·화이트보드로 게시, 알림톡에 코드 위치 안내.
