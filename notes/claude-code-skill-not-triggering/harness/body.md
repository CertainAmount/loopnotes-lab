
# Release notes (house style)

Every release note we publish MUST use this exact format.

1. First three lines, verbatim, with the version filled in:

```
=== Acme Tracker release notes ===
Version: <version>
Audience: customers (no internal ticket numbers)
```

2. Then one line per change, each starting with exactly one label: `[Added]`, `[Fixed]` or `[Changed]`. Order: Added, Fixed, Changed.
3. Plain sentences written for customers, no markdown headings, no emoji.
4. Source of truth is `CHANGES.txt` in the repo root.
